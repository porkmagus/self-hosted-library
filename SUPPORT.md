# Support

This community project is provided without a guaranteed response time. Before reporting a problem, update to a supported tagged release, reproduce it with the documented configuration, and protect your data with `./backup.sh`.

Include:

- application version and host OS/architecture;
- CPU/GPU mode and available memory/disk;
- `./doctor.sh --json` output;
- the failing command and sanitized logs;
- whether the problem occurs after a fresh install, upgrade, restore, or interrupted ingest.

Never attach deployment configuration, backup archives, credentials, copyrighted library content, or raw document text. Redact object keys and filenames when they reveal private material.

Security vulnerabilities should not be filed with exploit details in a public issue. Use GitHub's private security-advisory reporting for the repository when available.
